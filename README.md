# Panel firm

Statyczny interfejs do przeglądania własnego CSV, z mapą, profilami T/K i motywem jasnym/ciemnym.

Strona korzysta ze zwykłych plików index.html, style.css i modułów JavaScript. GitHub Pages nie wymaga skryptów budowania ani pakietów npm. Przy ręcznej aktualizacji wgraj wszystkie pliki strony do katalogu głównego repozytorium.

Otwórz stronę i wybierz Wczytaj CSV. Dane pozostają w Twojej przeglądarce, dopóki nie połączysz zewnętrznej bazy. Repozytorium nie zawiera listy firm ani notatek.

Publikacja: GitHub Pages, gałąź main, katalog główny (/).
