Połącz wspólną bazę klientów

Wybierz, z której bazy chcesz korzystać. Po połączeniu zmiany będą zapisywane we wspólnym CSV.

Wczyta bazę z GitHuba zamiast lokalnej kopii. Przy łączeniu niczego nie zapisze na GitHubie.

Właściciel repo: token fine-grained z Contents: Read and write. Zaproszony współpracownik osobistego repo: GitHub wymaga obecnie tokenu classic z zakresem repo (szerszy dostęp). Każda osoba używa własnego tokenu. Połączenie i token zostaną zapamiętane w tej przeglądarce. Tutaj możesz je zmienić; Rozłącz i zapomnij usuwa zapisane połączenie. Token fine-grained · Token classic .

Aby wysłać własną bazę, najpierw wczytaj ją przyciskiem Wczytaj CSV. Obecna lista obejmuje wszystkie firmy w panelu, również ukryte przez filtry.

Wskaż plik klienci.csv z folderu startup i pozwól przeglądarce zapisywać zmiany.

Bezpośrednie połączenie działa w Chrome i Edge. W pozostałych przeglądarkach możesz importować i eksportować CSV. Bez połączenia zmiany są zapisywane tylko w tej przeglądarce.
