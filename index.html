Połącz wspólną bazę klientów

Obie osoby łączą się z tym samym repozytorium. Każda zmiana statusu, notatki i telefonu zapisuje się we wspólnym CSV.

Właściciel repo: token fine-grained z Contents: Read and write. Zaproszony współpracownik osobistego repo: GitHub wymaga obecnie tokenu classic z zakresem repo (szerszy dostęp). Każda osoba używa własnego tokenu. Token zostaje tylko w pamięci karty; po odświeżeniu połącz się ponownie. Token fine-grained · Token classic .

Połączenie wczyta bazę z repozytorium. Nowych klientów z pliku AI dodasz potem przyciskiem Wczytaj CSV. Jeśli pliku jeszcze nie ma, panel pozwoli zapisać obecną listę.

Wskaż plik klienci.csv z folderu startup i pozwól przeglądarce zapisywać zmiany.

Bezpośrednie połączenie działa w Chrome i Edge. W pozostałych przeglądarkach możesz importować i eksportować CSV. Bez połączenia zmiany są zapisywane tylko w tej przeglądarce.
